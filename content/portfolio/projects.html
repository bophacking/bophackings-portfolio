Enzyme Topt Predictor

A computational biology project that predicts the temperature at which an enzyme works best (its optimal catalytic temperature) from its protein sequence. It compares two linear regression models: one that uses the sequence alone and one that also knows the optimal growth temperature of the host organism. Built with six teammates for a university course and inspired by Gado, Beckham and Payne (2020). It started as a Flask app, but you can try out the ported version here.

Python, scikit-learn, Biopython, JavaScript

SPICE: Restaurant Price Picker

My first machine learning project. Upload a restaurant menu as a CSV file and a linear regression model, trained on about 194,000 Malaysian menu records, estimates each selling price, labels it Cheap, Average or Expensive, and works out a rough profit. On held-out data it reaches R² 0.73. Also ported from Flask for you to try here.

Python, pandas, scikit-learn, JavaScript
